# E-portfolio de Matthieu Lopez

Site statique bilingue en français et en anglais, compatible avec GitHub Pages.

## Six rubriques

1. Bienvenue / Welcome
2. Formation d’ingénieur (projets) / Engineering courses (projects)
3. Engagement civique / Civic Engagement
4. Mobilité / Mobility
5. Carrière / Careers
6. Sports et centres d’intérêt / Sports and interests

## Publication

Décompresser le ZIP puis importer son contenu directement à la racine du dépôt, en conservant assets et .github. Dans Settings > Pages, choisir GitHub Actions. Le fichier .github/workflows/pages.yml publie la branche main. Le menu Actions permet de lancer manuellement la procédure « Publier le portfolio sur GitHub Pages ».

## Personnalisation

- contenu.js : textes français, coordonnées et portrait.
- contenu-en.js : traductions anglaises.
- rubriques.js : villes et interactions de la carte.
- assets/cv : CV et aperçus dans les deux langues.
- assets/projets : TIPE et 45 diapositives.
- assets/mobilite : photographies et données de carte.

Les récits de voyage sont à compléter. Les images de voyage sont des photos d’illustration ; conserver les crédits et les licences, décrits dans CREDITS-PHOTOS.md.

Le portrait est intégré sur le site et dans les deux CV. La vidéo finale est intégrée et se lance directement dans le lecteur. Le guide MODIFICATIONS.md donne les étapes de modification sur GitHub.
