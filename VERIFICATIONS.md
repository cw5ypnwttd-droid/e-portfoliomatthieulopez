# Vérifications de la première version

- Syntaxe JavaScript : valide.
- Contrôles exécutés avec un DOM simulé : filtres de projets, ouverture et fermeture des détails, classement décroissant de la timeline, contacts vides et renseignés, message CV sans PDF.
- Tous les fichiers locaux référencés par les pages HTML existent.
- Résolution des chemins vérifiée avec une URL de dépôt GitHub Pages en sous-dossier.
- Menu mobile, styles adaptatifs, focus clavier et réduction des animations présents dans le code.

## Limite de vérification

Le serveur HTTP local a été refusé par l’environnement et le navigateur de test n’a pas pu démarrer. L’affichage réel sur ordinateur et mobile, la lecture multimédia, le presse-papiers et l’aperçu PDF n’ont donc pas été validés dans un navigateur. Les contrôles avec DOM simulé ne remplacent pas une vérification visuelle. Les médias personnels ne sont pas encore renseignés.

Aucun dépôt connecté, aucune publication effectuée.
