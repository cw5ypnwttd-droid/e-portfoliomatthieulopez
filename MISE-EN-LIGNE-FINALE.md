# Mettre cette version finale en ligne sur GitHub

1. Décompressez le ZIP.
2. Ouvrez votre dépôt GitHub et l’onglet Code.
3. Utilisez Add file > Upload files pour remplacer les fichiers aux mêmes emplacements.
4. Importez les fichiers et dossiers à l’intérieur du dossier décompressé, sans ajouter un dossier englobant.
5. Le dossier assets/video doit contenir presentation-matthieu-lopez.mp4 et couverture.jpg.
6. Si GitHub refuse tout le dossier en un seul envoi, importez les fichiers de la racine et .github, puis assets en plusieurs envois en conservant les chemins.
7. Dans Settings > Pages, choisissez GitHub Actions. Le workflow fourni publie la branche main.
8. Une fois l’exécution verte dans Actions, ouvrez le lien donné par Settings > Pages.
9. Dans Carrière, le lecteur de présentation apparaît à côté des destinations d’échange. Cliquez sur Lecture au centre de la vidéo ou dans ses commandes. Sur téléphone, il apparaît au-dessus des destinations.

Le même fichier vidéo est proposé dans les deux versions du site. L’image reste verticale, sans recadrage.

Pour les prochaines mises à jour, seuls les fichiers modifiés doivent être remplacés ; il n’est pas nécessaire de réimporter la vidéo à chaque changement de texte.

La vidéo est optimisée pour le Web : environ 22 Mo, 720 × 1280, H.264 et son AAC. Sa durée complète est conservée, environ 3 min 03 s. Le fichier original reste intact.
